Una lista para que no te falte nada (y algunas ideas para pasarlo aún mejor).

¿Qué llevo al PyCamp? 🎒

¡Hola! 👋

Falta una semana y seguro que ya estás pensando en la maleta. Aquí van algunas ideas para que no te falte nada. No todo es obligatorio, pero sí recomendable.

Lo básico

  • Ropa y calzado cómodos, y algo de abrigo para las noches
  • Productos de higiene personal (toalla, cepillo de dientes, champú, jabón…)
  • Tapones para los oídos (mejor prevenir que curar 😉)
  • Medicamentos que tomes habitualmente
  • Protector solar y repelente de mosquitos
  • Traje de baño, por si el venue tiene piscina

Para programar

  • Portátil, cargador y todo lo que necesites para programar cómodamente durante muchas horas (ratón, cables USB…)
  • Regleta o alargador de corriente
  • Adaptadores de corriente, si vienes de fuera de España
  • Batería externa

Para pasarlo aún mejor

  • Juegos de mesa (¡o cualquier otro juego!)
  • Pelota, malabares, un instrumento musical…
  • Componentes electrónicos para algún proyecto (Raspberry Pi, pantallas, cables, soldador…)
  • Algo rico para compartir 🍬

El venue pone la ropa de cama, la manta y la almohada, pero si lo prefieres puedes traer las tuyas.
